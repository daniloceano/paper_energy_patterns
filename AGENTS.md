# Agent instructions

## Protected Overleaf backup

`docs/energy_patterns_clim_dyn/` is a read-only backup of the manuscript project maintained
in Overleaf. Overleaf is the only working copy and the canonical source for everything in
that directory.

Agents must not create, edit, overwrite, rename, delete, format, compile, regenerate, or
synchronize any file under `docs/energy_patterns_clim_dyn/`. Agents must also not copy
newly generated figures or results into that directory. Danilo updates this backup manually
and only occasionally from Overleaf.

For computational work, use the repository's active locations such as `scripts/`, `results/`,
`figures/`, and `web/`. Treat `docs/energy_patterns_clim_dyn/` as reference-only material.
