# Legacy EP Structure Data

> ⚠️ **LEGACY/ARCHIVED** — These data products were generated by the EP1-vs-EP2 analysis that was superseded in April 2026.

## What This Contains

This directory preserves data products from the **legacy EP structure analysis** that compared EP1 and EP2 cyclones using climatology-based anomalies.

## Data Products

### Precomputed Composites (Legacy)
- `precomputed_composites_ep1_full_intensification.nc`
- `precomputed_composites_ep2_full_intensification.nc`
- `precomputed_composites_ep1_central_time.nc`
- `precomputed_composites_ep2_central_time.nc`
- `precomputed_composites_ep1_intense_10.nc`
- `precomputed_composites_ep2_intense_10.nc`

### Climatology Files (Used for Anomalies)
- `era5_climatology_250hPa.nc` — u, v, z at 250 hPa
- `era5_climatology_pv200.nc` — u, v, t at 175/200/225 hPa
- `era5_climatology_pv850.nc` — u, v, t at 825/850/875 hPa
- `era5_climatology_mfd975.nc` — u, v, q at 975 hPa
- `era5_climatology_slp.nc` — msl (single-level)

## Why This Was Superseded

The legacy analysis defined anomalies as departures from monthly climatology:
```
anomaly = field - monthly_climatology
```

The new canonical analysis defines anomalies relative to the total cyclone composite:
```
anomaly = EPx_composite - EPALL_composite
```

This change better isolates what distinguishes each Energy Pattern from the average cyclone.

## New Canonical Data Location

Current data products are in `data/era5_ep_structure/`.
